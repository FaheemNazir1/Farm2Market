# Manual API Test Fixtures

These HTML files provide a lightweight way to test backend endpoints directly in the browser without loading the React frontend.

## Available Test Fixtures

- **[test-order.html](file:///d:/Project/Farm2Market/tests/manual/test-order.html)**: Tests buyer authentication and order creation flow.
- **[test-registration.html](file:///d:/Project/Farm2Market/tests/manual/test-registration.html)**: Tests user registration endpoint.
- **[test-validation.html](file:///d:/Project/Farm2Market/tests/manual/test-validation.html)**: Tests payload validation and error responses.

## How to Run

1. Ensure backend is running (`npm run dev:server` or `npm run dev`).
2. Open any of the `.html` files in your web browser directly or via a local live server.
3. Click the test buttons and view the JSON response payload.
